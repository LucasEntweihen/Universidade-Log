## ordem de regras e fluxo de programação
1. dê um **git pull** todas as vezes para ter a versão mais recente do projeto
2. Leia o projeto inteiro antes de fazer as alterações
3. Pense adequadamente em como será feito isso
4. Adicione as modificações escritas de forma direta e complexa ao @CHANGELOG.md
5. ao fim de cada modificação faça um **git add .** , **git commit -m "<menssage>"** e **git push**
6. quando for pedido uma modificação priorize a modificação via git

## considere sempre
1. escreva as modificações sem alterar os códigos com temas e pedidos paralelos, que não tenham haver com o pedido original
2. opte por me perguntar sobre as coisas via lista
