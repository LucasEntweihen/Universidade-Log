## ordem de regras e fluxo de programação
1. Leia o projeto inteiro antes de fazer as alterações
2. Pense adequadamente em como será feito isso
3. Adicione as modificações escritas de forma direta e complexa ao @CHANGELOG.md
4. ao fim de cada modificação faça um **commit** com um nome adequado e descrição
5. quando for pedido uma modificação priorize a modificação via git

## considere sempre
- escreva as modificações sem alterar os códigos com temas e pedidos paralelos, que não tenham haver com o pedido original
- opte por me perguntar sobre as coisas via lista
