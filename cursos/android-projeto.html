Passo 1: O Motoboy (Retrofit + Coroutines)

1

Defina o modelo de dados

data class Item(
    val id: Int,
    val titulo: String,
    val urlFoto: String
)

Crie a interface que descreve o endpoint. Repare que a função é suspend: é isso que permite ao Retrofit rodar em segundo plano sem travar a tela:

interface ApiService {
    @GET("itens")
    suspend fun buscarItens(): List<Item>
}

Passo 2: O Gerente (ViewModel)

2

Processe e exponha os dados com segurança

O ViewModel chama o Repository dentro de viewModelScope, guarda o resultado num StateFlow e nunca deixa a View saber como os dados foram buscados:

class ListaViewModel(private val repository: ItemRepository) : ViewModel() {
    private val _itens = MutableStateFlow<List<Item>>(emptyList())
    val itens: StateFlow<List<Item>> = _itens

    fun carregar() {
        viewModelScope.launch {
            _itens.value = repository.buscarItens()
        }
    }
}

Passo 3: A Tela (Activity/Fragment)

3

Só observe: nada de lógica de negócio aqui

viewModel.itens.observe(this) { lista ->
    adapter.submitList(lista)
}
viewModel.carregar()

É só isso. A Activity nunca sabe que existe uma API, um Retrofit ou uma Coroutine rodando: ela só reage quando os dados chegam.

Passo 4: Os Pintores (Adapter + Glide)

4

Infle a célula e baixe a imagem

class ItemAdapter : ListAdapter<Item, ItemAdapter.VH>(DiffCallback()) {
    class VH(val binding: ItemCellBinding) : RecyclerView.ViewHolder(binding.root)

    override fun onBindViewHolder(holder: VH, position: Int) {
        val item = getItem(position)
        holder.binding.tvTitulo.text = item.titulo
        Glide.with(holder.binding.root)
            .load(item.urlFoto)
            .centerCrop()
            .into(holder.binding.imgFoto)
    }
}

O Glide cuida de baixar, redimensionar e colocar em cache a imagem: inclusive cancelando o download automaticamente se a célula for reciclada antes de terminar.

O fluxo completo, de novo

Retrofit busca → ViewModel processa e guarda → Activity observa e repassa → Adapter + Glide desenham cada célula. Cada seta é uma fronteira que a camada seguinte não deveria atravessar.

Checklist de conclusão

Se todos esses pontos fazem sentido, o projeto está de pé:

  • A Activity não importa Retrofit em nenhum lugar do código.
  • O ViewModel não conhece nenhuma View ou Context.
  • O Adapter usa ListAdapter + DiffUtil, não notifyDataSetChanged().
  • A lista rola suave mesmo com dezenas de imagens carregando.
